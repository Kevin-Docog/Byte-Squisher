How this runs: every compression step happens on your device — files are never uploaded anywhere. Image uses only the canvas API, no internet needed. Video and Audio use ffmpeg.wasm — real ffmpeg compiled to WebAssembly — which needs a proper https:// origin (this is why it must be hosted, e.g. on GitHub Pages, rather than opened as a local file). PDF and DOCX use pdf.js/pdf-lib and JSZip. All of these load from a CDN the first time you use them. If you host this page alongside its sw.js file, a service worker caches the page and every helper library the first time you visit while online, then serves it all from that cache on every visit after — including Video and Audio — with or without internet.
